# La Mesasa - Tienda Online

## Descripción del Proyecto
La Mesasa es una aplicación web de comercio electrónico desarrollada en React con Vite. La tienda está orientada a la venta de muebles de madera artesanales y de diseño moderno. 

La aplicación ofrece una experiencia fluida como Single Page Application (SPA), incluyendo:
- **Página de Inicio:** Banner promocional, accesos rápidos por categorías y presentación de la marca.
- **Catálogo de Productos:** Listado con filtros por categoría y barra de búsqueda.
- **Detalle de Producto:** Vista individual con especificaciones técnicas y control de stock disponible.
- **Carrito de Compras:** Gestión completa de compras (agregar productos, modificar cantidades con límite de stock, eliminar artículos, cálculo automático de totales y vaciar carrito).
- **Formulario de Compra:** Formulario interactivo para registrar los datos del cliente y confirmar el pedido generando un número de orden.
- **Página de Contacto:** Información de la tienda, horarios de atención y mapa integrado con Google Maps.
- **Diseño Responsive:** Totalmente adaptado para celulares y computadoras de escritorio.

---

## Tecnologías Utilizadas
- **React 19:** Biblioteca principal para la construcción de la interfaz basada en componentes y hooks (`useState`, `useEffect`, `useParams`, `useLocation`, `useSearchParams`).
- **Vite:** Entorno de desarrollo rápido y empaquetador para producción.
- **React Router DOM 7:** Manejo de rutas y navegación declarativa sin recargar la página.
- **Bootstrap 5:** Sistema de grillas y clases utilitarias para la maquetación.
- **CSS3 / Vanilla CSS:** Estilos personalizados, diseño responsive con media queries y paleta de colores centralizada con variables CSS.
- **JavaScript (ES6+):** Lógica funcional, manejo de arrays, eventos y manipulación de estado.

## Instrucciones para Instalar y Correr el Proyecto

### Prerrequisitos
- Tener instalado Node.js (versión 18 o superior) en el sistema.

### Pasos de instalación

1. **Clonar el repositorio o descargar el proyecto:**
   ```bash
   git clone https://github.com/Ocampo-Matias/Trabajo_practico_-_Tienda_online_en_React.git
   ```

2. **Ingresar a la carpeta del proyecto:**
   ```bash
   cd Trabajo_practico_-_Tienda_online_en_React
   ```

3. **Instalar las dependencias:**
   ```bash
   npm install
   ```

4. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

5. **Abrir en el navegador:**
   Ingresar a la dirección local que indique la consola (generalmente `http://localhost:5173/`).
